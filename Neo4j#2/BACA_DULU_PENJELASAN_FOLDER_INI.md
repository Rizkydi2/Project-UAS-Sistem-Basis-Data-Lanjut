# Penjelasan Folder Ini

*Topik resmi Kelompok 1: Topik #1 — Smart Tour Router*
(Sistem Optimalisasi Rute & Manajemen Logistik Perjalanan)

Seluruh isi laporan utama, pipeline BaseX/MongoDB/Neo4j, dan Advanced Cypher
Query "Dynamic Dijkstra Shortest Path with Constraints" pada folder
`neo4j_renamed_dan_dokumentasi/` adalah **jawaban utama** kelompok untuk
memenuhi requirement UAS Tahap 2, sesuai topik yang dipilih.

## Isi folder ini (ekstensi tambahan, di luar topik utama)

Query-query pada folder ini — node `Media`, `Investor`, `Proyek`, relasi
`MEMBERITAKAN` dan `MENDANAI`, serta kueri agregasi
*"Multilayered Sentiment-Investment Impact Analysis"* — merupakan
**eksperimen tambahan bersifat kreatif/eksploratif**, dibuat sebagai bentuk
uji coba mandiri kelompok untuk memperluas graf pariwisata (Topik #1) dengan
lapisan dampak ekonomi/investasi terhadap destinasi wisata (query terakhir
pada `Perluas ke lapisan wilayah.png` menghubungkan node `Proyek` ke wilayah
destinasi wisata melalui `BERLOKASI_DI`).

**Ini BUKAN berarti kelompok mengerjakan Topik #2 (Tour-Econ Sentiment
Nexus).** Kelompok tetap mengerjakan dan mengumpulkan Topik #1 secara utuh.
Folder ini disertakan semata sebagai bukti eksplorasi tambahan/nilai plus,
bukan sebagai pengganti atau bagian wajib dari jawaban Topik #1.

Jika dosen/asisten menilai folder ini tidak relevan untuk topik yang
dipilih, folder ini dapat diabaikan sepenuhnya tanpa memengaruhi penilaian
komponen wajib Topik #1 yang ada di folder `neo4j_renamed_dan_dokumentasi/`.

## Rekomendasi jika ingin dicantumkan di laporan akademik

Cantumkan sebagai sub-bagian terpisah di akhir bagian **Analisis dan
Pembahasan**, dengan judul misalnya:

> "5.x Eksplorasi Tambahan (Opsional): Korelasi Sentimen Media dan Investasi
> terhadap Destinasi Wisata"

dan jelaskan secara eksplisit bahwa ini adalah pengembangan mandiri di luar
cakupan wajib topik, bukan bagian dari jawaban inti Advanced Cypher Query
Topik #1.
