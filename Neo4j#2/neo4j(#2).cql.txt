STEP 5 — Hitung bobot efektif (penalti otomatis)
Ini query INTI yang jadi bukti "dynamic constraint":

cypher
MATCH (a:Wisata)-[r:JALUR_KE]->(b:Wisata)
SET r.weight = CASE
  WHEN a.status IN ['closed','banjir'] OR b.status IN ['closed','banjir']
    THEN r.distance + 1000
  ELSE r.distance
END;

Screenshot hasil query ini sebagai bukti "Set Bobot Efektif dengan Penalti".

STEP 6 — Ganti shortestPath() yang error, pakai APOC Dijkstra
Ini yang gantiin query kamu yang error kemarin:

cypher
MATCH (start:Wisata {nama_wisata: 'Pantai Kuta'}),
      (end:Wisata {nama_wisata: 'Tanah Lot'})
CALL apoc.algo.dijkstra(start, end, 'JALUR_KE>', 'weight')
YIELD path, weight
RETURN [n IN nodes(path) | n.nama_wisata] AS rute, weight;

Kalau ini jalan tanpa error dan keluar hasil rute + weight → selesai, ini query utama kamu buat laporan.

STEP 7 — Bukti "constraint-nya beneran ngefek" (penting buat Analisis di laporan)
Jalankan Dijkstra yang sama, tapi dengan pasangan destinasi yang TIDAK closed, biar bisa dibandingkan rute-nya beda:

MATCH (start:Wisata {nama_wisata: 'Kebun Binatang Bandung'}),
      (end:Wisata {nama_wisata: '23 Paskal Shopping Center'})

// Ini pengganti shortestPath() bawaan yang error (shortestPath() cuma hop-count,

YIELD path, weight
RETURN [n IN nodes(path) | n.nama_wisata]      AS rute,
       [r IN relationships(path) | r.distance] AS jarak_asli_km,
       weight                                   AS total_bobot_efektif;

STEP 5 — ADVANCED CYPHER QUERY: Multilayered Sentiment-Investment Impact Analysis (query utama)

Query ini mendeteksi korelasi berjenjang struktural: rata-rata sentimen publikasi media global per proyek, ditelusuri sampai ke lapisan keputusan pendanaan investor, lalu dikorelasikan dengan tren sentimen dari waktu ke waktu.

cypher
MATCH (m:Media)-[b:MEMBERITAKAN]->(pr:Proyek)
WITH pr,
     avg(b.skor_sentimen)                         AS rata_rata_sentimen,
     count(DISTINCT m)                            AS jumlah_media_meliput,
     collect(b.skor_sentimen)[0]                  AS sentimen_awal,
     collect(b.skor_sentimen)[-1]                 AS sentimen_terbaru
OPTIONAL MATCH (i:Investor)-[d:MENDANAI]->(pr)
WITH pr, rata_rata_sentimen, jumlah_media_meliput,
     sentimen_terbaru - sentimen_awal             AS tren_sentimen,
     count(DISTINCT i)                            AS jumlah_investor,
     sum(d.jumlah_usd)                            AS total_dana_usd
RETURN pr.nama_proyek                             AS proyek,
       pr.sektor                                  AS sektor,
       round(rata_rata_sentimen, 2)               AS rata_rata_sentimen,
       round(tren_sentimen, 2)                    AS tren_sentimen_naik_turun,
       jumlah_media_meliput,
       jumlah_investor,
       coalesce(total_dana_usd, 0)                AS total_dana_usd,
       CASE
         WHEN tren_sentimen > 0 AND coalesce(total_dana_usd,0) > 0
           THEN "Sentimen naik & pendanaan mengikuti (impact positif)"
         WHEN tren_sentimen < 0 AND coalesce(total_dana_usd,0) = 0
           THEN "Sentimen turun & tidak ada pendanaan (impact negatif)"
         WHEN tren_sentimen < 0 AND coalesce(total_dana_usd,0) > 0
           THEN "Sentimen turun tapi masih didanai (butuh investigasi lanjut)"
         ELSE "Netral / data belum cukup"
       END                                        AS interpretasi_korelasi
ORDER BY rata_rata_sentimen DESC;

Cara membaca hasil untuk laporan:

Kereta Cepat Bandung Raya → sentimen naik terus (0.65 → 0.72 → 0.80) dan didanai 3x oleh 2 investor berbeda → mendukung argumen "sentimen positif berjenjang mendorong keputusan pendanaan konsorsium investor".
Jalan Tol Trans Banten → sentimen negatif dan nol pendanaan → membuktikan arah sebaliknya juga konsisten.

Screenshot hasil query ini sebagai bukti utama "Advanced Cypher Query: Multilayered Sentiment-Investment Impact Analysis".

STEP 6 — Perluas ke lapisan wilayah (menyambung ke graph pariwisata lama)

Ini membuktikan graf-nya benar-benar "terhubung secara fungsional" lintas domain (bisnis + pariwisata), bukan graph terpisah:

cypher
MATCH (m:Media)-[b:MEMBERITAKAN]->(pr:Proyek)-[:BERLOKASI_DI]->(p:Provinsi)
OPTIONAL MATCH (w:Wisata)-[:BERLOKASI_DI]->(:KotaKabupaten)-[:BAGIAN_DARI]->(p)
WITH p.provinsi AS provinsi,
     avg(b.skor_sentimen) AS rata_rata_sentimen_proyek,
     count(DISTINCT w) AS jumlah_destinasi_wisata_terdampak
RETURN provinsi, round(rata_rata_sentimen_proyek,2) AS rata_rata_sentimen_proyek, jumlah_destinasi_wisata_terdampak
ORDER BY rata_rata_sentimen_proyek DESC;
